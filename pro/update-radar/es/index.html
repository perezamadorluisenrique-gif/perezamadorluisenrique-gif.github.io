Qué hace y para quién

Update Radar te dice qué plugins de la comunidad tienen una actualización. Pro es para quien mantiene muchos plugins y no puede permitirse una bóveda rota tras actualizar: copia cada plugin antes, te deja volver atrás y te ayuda a encontrar al culpable cuando algo deja de funcionar.

Necesita el plugin gratuito Update Radar (0.5.0 o posterior).

Qué añade Pro

  • Copias antes de cada actualizaciónAntes de que Update Radar instale una actualización, Pro copia los archivos del plugin en tu carpeta de configuración. Puedes restaurar cualquier copia más adelante; el plugin se recarga y Update Radar deja de ofrecer la versión nueva.
  • Puntos de restauraciónLa versión de cada plugin y cuáles están activados. Pro crea uno antes de Update all, y Go back to a restore point muestra qué cambiaría y pregunta antes.
  • Encuentra el plugin que causa un problemaUna búsqueda guiada que desactiva y activa plugins por mitades y te pregunta si el problema sigue, hasta que queda uno. Al final tus plugins vuelven a estar como estaban.
  • Inspeccionar una actualizaciónCompara la versión nueva con la instalada: tamaño, servidores web nuevos o desaparecidos, patrones que merecen una mirada y cambios en el manifiesto. Son indicios, no veredictos; no se ejecuta nada.
  • Resumen de notas de versiónEscribe una nota con las notas de versión de hasta 20 actualizaciones pendientes, con enlaces y código neutralizados por seguridad.
  • Reglas de actualizaciónPor plugin: todas las actualizaciones, solo menores y mayores, solo mayores o fijado, y una espera de 1 a 30 días.

Lo que sigue siendo gratis, para siempre

  • Actualizaciones en la barra de estado y una lista de qué ha cambiado, con las notas de versión.
  • Actualizar un plugin o todos, ignorar una versión, posponer un plugin, esperar antes de que se ofrezca una actualización.
  • Volver a una versión anterior de un plugin.
  • Comprobaciones de compatibilidad y avisos de estado (retirado, abandonado, no procede del directorio).

Nada del plugin gratuito pasa a Pro. Cuando termina la prueba, restaurar copias y puntos de restauración, la búsqueda y borrar copias siguen funcionando; crear copias nuevas, inspeccionar, los resúmenes y las reglas requieren una clave.

Preguntas frecuentes

¿Necesito el plugin gratuito?

Sí. Update Radar Pro necesita el plugin gratuito Update Radar (0.5.0 o posterior) y este debe estar en marcha para las copias antes de actualizar, las reglas y el resumen.

¿Pueden las copias contener secretos?

El data.json de un plugin puede guardar tokens o contraseñas, y una copia es un archivo normal. Desactiva Include data.json si no lo quieres. Delete all snapshots lo borra todo.

¿Qué pasa cuando termina la prueba?

Restaurar, volver a un punto de restauración, la búsqueda y borrar copias siguen funcionando. Las copias nuevas, inspeccionar, los resúmenes y las reglas requieren una clave.

¿Actualiza plugins por su cuenta?

No. Nunca instala ni actualiza un plugin sin que tú lo pidas.
