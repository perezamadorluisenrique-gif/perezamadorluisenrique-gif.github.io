Text Case Pro

Limpia carpetas enteras con tus propias recetas, con vista previa y deshacer, y pega texto limpio desde PDF, páginas web y correo.

Próximamente 12 USDpago único

Qué hace y para quién

Text Format cambia mayúsculas y minúsculas y limpia la selección o la nota actual. Pro es para el día en que necesitas limpiar muchas notas de la misma manera: guarda tus pasos como recetas, las ejecuta sobre una carpeta o el vault con vista previa y deshacer en un paso, y limpia el texto pegado según de dónde venga.

Funciona mejor con el plugin gratuito Text Format instalado, y necesita Obsidian 1.7.2 o posterior.

Qué añade Pro

  • RecetasCadenas con nombre de limpiezas, cambios de mayúsculas y tus reemplazos guardados, cada una con su comando y su atajo.
  • Limpiar una carpeta o todo el vaultUna vista previa de cada nota con una casilla por nota; nada cambia hasta que confirmas.
  • Deshacer todo el loteUn comando devuelve cada nota a su estado; una nota que hayas editado después nunca se sobrescribe.
  • Informe de lo que cambióUna nota que enumera lo que cambió cada paso en cada nota, con enlaces.
  • Perfiles de pegadoPDF, página web o correo: guiones y saltos de línea unidos de nuevo, citas de respuesta y firmas eliminadas.
  • Unir palabras partidas con excepcionesinfor- / mación se convierte en información, mientras que self- / service sigue siendo self-service.

Lo que sigue siendo gratis, para siempre

  • Comandos de mayúsculas y minúsculas y estilos de identificadores (camelCase, snake_case, slug y más).
  • Ordenar la nota y limpiar al pegar.
  • Comandos de buscar y reemplazar guardados.
  • Ordenar, quitar duplicados y quitar líneas en blanco.

Nada del plugin gratuito pasa a Pro.

Preguntas frecuentes

¿Necesito el plugin gratuito?

Pro funciona mejor con el plugin gratuito Text Format instalado. El gratuito sigue siendo gratis y sigue haciendo lo que hace hoy.

¿Puedo deshacer un lote?

Sí. Un comando devuelve cada nota del lote a su estado. Una nota que hayas editado después nunca se sobrescribe.

¿Cambia mis notas sin preguntar?

No. Limpiar una carpeta o el vault muestra una vista previa con una casilla por nota, y nada cambia hasta que confirmas.

¿Qué recibo por el precio?

El plugin para siempre, para tu uso, más un año de actualizaciones. Después sigue funcionando; puedes renovar por la mitad del precio para seguir recibiendo actualizaciones.
