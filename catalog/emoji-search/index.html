Emoji Search

Insert emojis from a searchable picker or by typing a :shortcode.

Install from the Obsidian directory Open in Obsidian Source code and issues

What it does

Insert emojis from a searchable picker or by typing a :shortcode.

Open a picker with every emoji, or type :smi in a note and pick from a list. It works offline, in any note, on desktop and mobile.

Highlights

  • Every emoji is on one scrolling page, in sections. The tabs jump to a section.
  • Search by name, keyword or shortcode (party, thumbs, +1), without accents, in any word order, or paste an emoji to find it.
  • Arrow keys move, Enter inserts, Shift+Enter inserts and keeps the picker open, Esc clears the search and then closes.
  • The hand button next to the search field sets your skin tone. Mouse and keyboard use the same one.
  • Frequently used emojis are listed first and rank higher in search and suggestions.
  • With several cursors or selections, it inserts at all of them in one step. In reading view it copies the emoji instead of editing your note.
