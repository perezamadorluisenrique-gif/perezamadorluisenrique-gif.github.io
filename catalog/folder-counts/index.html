Folder Counts

Show how many notes or files each folder holds in the file explorer, with a vault total, file type filters and folder exclusions.

Install from the Obsidian directory Open in Obsidian Source code and issues

What it does

See how many notes each folder holds, right in the file explorer.

The numbers update by themselves as you create, delete, move and rename files. Hover a number to see what is behind it, for example "91 notes in total · 1 directly inside · 3 subfolders".

Works on desktop and mobile.
