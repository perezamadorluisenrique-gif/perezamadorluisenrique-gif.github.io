Qué hace Line Editing Commands

Line-level editing commands for Obsidian's editor: duplicate, join, sort, reverse, insert blank lines, select a line, delete to the start or end of a line, jump to a line number, and build multiple cursors the way code editors do (select next occurrence, select all, skip, add cursor above or below). Every command works with several cursors at once, and a single Undo reverts it.

Cómo cambiar de Remove Newlines a Line Editing Commands

  1. Instala Line Editing Commands desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Remove Newlines sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Line Editing Commands y revísalos una vez: los ajustes de Remove Newlines no se copian.
  4. Cuando todo te funcione como esperas, desinstala Remove Newlines.
