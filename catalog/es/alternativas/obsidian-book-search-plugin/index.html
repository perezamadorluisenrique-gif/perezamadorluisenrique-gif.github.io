Qué hace Book Lookup

Create a note for any book from Open Library or Google Books: search by title, author or ISBN, pick the result, and get a note with properties, a cover and a description.

Cómo cambiar de Book Search a Book Lookup

  1. Instala Book Lookup desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Book Search sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Book Lookup y revísalos una vez: los ajustes de Book Search no se copian.
  4. Cuando todo te funcione como esperas, desinstala Book Search.
