Qué hace Folder Counts

See how many notes each folder holds, right in the file explorer.

Cómo cambiar de File Explorer Note Count a Folder Counts

  1. Instala Folder Counts desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva File Explorer Note Count sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Folder Counts y revísalos una vez: los ajustes de File Explorer Note Count no se copian.
  4. Cuando todo te funcione como esperas, desinstala File Explorer Note Count.
