Qué hace Run Code Blocks

Adds a Run button to code blocks and shows the output right below, for JavaScript, Python, shell and more.

Cómo cambiar de Code Emitter a Run Code Blocks

  1. Instala Run Code Blocks desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Code Emitter sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Run Code Blocks y revísalos una vez: los ajustes de Code Emitter no se copian.
  4. Cuando todo te funcione como esperas, desinstala Code Emitter.
