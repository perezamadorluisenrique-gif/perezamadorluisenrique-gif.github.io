Qué hace Random Note Filters

Open or link a random note from a folder, tag, property or the current search results.

Cómo cambiar de Improved Random Note a Random Note Filters

  1. Instala Random Note Filters desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Improved Random Note sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Random Note Filters y revísalos una vez: los ajustes de Improved Random Note no se copian.
  4. Cuando todo te funcione como esperas, desinstala Improved Random Note.
