Qué hace Spreadsheet to Table

Table tools for Markdown notes: paste spreadsheet cells as a table, edit rows and columns from commands (so it works in source mode and on a phone), sort, align, and copy a table out as rich text, CSV or spreadsheet cells.

Cómo cambiar de Excel to Markdown Table a Spreadsheet to Table

  1. Instala Spreadsheet to Table desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Excel to Markdown Table sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Spreadsheet to Table y revísalos una vez: los ajustes de Excel to Markdown Table no se copian.
  4. Cuando todo te funcione como esperas, desinstala Excel to Markdown Table.
