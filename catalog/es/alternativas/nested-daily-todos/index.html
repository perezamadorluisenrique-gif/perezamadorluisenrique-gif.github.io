Qué hace Task Rollover

Unfinished tasks from yesterday's daily note show up in today's, by themselves, the moment today's note is created.

Cómo cambiar de Nested Daily Todos a Task Rollover

  1. Instala Task Rollover desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Nested Daily Todos sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Task Rollover y revísalos una vez: los ajustes de Nested Daily Todos no se copian.
  4. Cuando todo te funcione como esperas, desinstala Nested Daily Todos.
