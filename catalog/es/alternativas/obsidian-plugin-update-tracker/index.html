Qué hace Update Radar

Checks your installed community plugins and themes for updates in the background, shows what changed, and tells you which plugins look abandoned. A successor to Plugin Update Tracker, which has not had a release in over a year.

Cómo cambiar de Plugin Update Tracker a Update Radar

  1. Instala Update Radar desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Plugin Update Tracker sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Update Radar y revísalos una vez: los ajustes de Plugin Update Tracker no se copian.
  4. Cuando todo te funcione como esperas, desinstala Plugin Update Tracker.

De dónde salen estos datos

Nombre, autor, descripción, versión, fecha de la última actualización y descargas vienen de los archivos públicos del directorio de Obsidian (community-plugins.json y community-plugin-stats.json), leídos el 24 de noviembre de 2026. Las descargas son las que publica Obsidian.

Esta página la escribe la persona que hace Update Radar. Si mantienes Plugin Update Tracker y quieres corregir o retirar algo, abre una incidencia en el repositorio y se atiende.

Todo este catálogo es gratuito y de código abierto. Las páginas se generan a partir del README y el manifiesto de cada producto, así que coinciden con la última versión.
