Qué hace Explorer Colors Plus

Color files and folders in the file explorer, with a palette, cascading to children, and import from File Color.

Cómo cambiar de File Color a Explorer Colors Plus

  1. Instala Explorer Colors Plus desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva File Color sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Explorer Colors Plus y revísalos una vez: los ajustes de File Color no se copian.
  4. Cuando todo te funcione como esperas, desinstala File Color.
