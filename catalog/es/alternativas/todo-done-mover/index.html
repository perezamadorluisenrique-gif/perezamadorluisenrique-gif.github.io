Qué hace Task Archive

Moves completed tasks, with their sub-items, into an archive section or note.

Cómo cambiar de To-Do to Done Mover a Task Archive

  1. Instala Task Archive desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva To-Do to Done Mover sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Task Archive y revísalos una vez: los ajustes de To-Do to Done Mover no se copian.
  4. Cuando todo te funcione como esperas, desinstala To-Do to Done Mover.
