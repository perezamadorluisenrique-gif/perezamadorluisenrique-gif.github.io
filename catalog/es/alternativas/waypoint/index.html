Qué hace Folder Index Notes

Keeps an index note in each folder up to date with links to the notes and subfolders inside it.

Cómo cambiar de Waypoint a Folder Index Notes

  1. Instala Folder Index Notes desde Instalar desde el directorio de Obsidian.
  2. En Ajustes, Plugins de la comunidad, desactiva Waypoint sin borrarlo. Así los dos no actúan a la vez sobre la misma acción.
  3. Abre los ajustes de Folder Index Notes y revísalos una vez: los ajustes de Waypoint no se copian.
  4. Cuando todo te funcione como esperas, desinstala Waypoint.
