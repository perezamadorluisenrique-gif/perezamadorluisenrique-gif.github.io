Spreadsheet to Table

Table tools for Markdown notes: paste cells from Excel or Google Sheets with a real header row, add, move and delete rows and columns, sort, align, and copy a table as rich text, CSV or for a spreadsheet.

Instalar desde el directorio de Obsidian Abrir en Obsidian Código fuente e incidencias

Qué hace

El texto que describe el producto está en inglés, igual que en su repositorio.

Table tools for Markdown notes: paste spreadsheet cells as a table, edit rows and columns from commands (so it works in source mode and on a phone), sort, align, and copy a table out as rich text, CSV or spreadsheet cells.

Copy cells in Excel, Google Sheets, Numbers or LibreOffice Calc, paste them into a note, and get a Markdown table, with the first row as its header.

Copied from the spreadsheet (a tab between cells):

Lo más destacado

  • escapes a | inside a cell, which would otherwise split it in two;
  • keeps a line break inside a cell as <br>, instead of breaking the row;
  • keeps the table inside the callout, quote or list item you paste it into, repeating the > on every line or indenting it to the item.
