How to choose

Check when each plugin was last updated, whether its description covers exactly what you need, and whether it supports your version of Obsidian. Downloads tell you how many people installed a plugin, not which one works better. Try one at a time on a copy of your vault.

  • Check in the Plugin Inspector: Link Embed
  • Check in the Plugin Inspector: Convert url to preview (iframe)
  • Check in the Plugin Inspector: URL Enricher

Where these facts come from

Name, author, description, version, last-update date and downloads come from the public Obsidian directory files (community-plugins.json and community-plugin-stats.json), read on 21 November 2026. Download counts are the ones Obsidian publishes.
