What Folder Index Notes does

Keeps an index note in each folder up to date with links to the notes and subfolders inside it.

How to switch from Waypoint to Folder Index Notes

  1. Install Folder Index Notes from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Waypoint off without deleting it, so the two do not act on the same action at once.
  3. Open the Folder Index Notes settings and review them once: settings from Waypoint are not copied over.
  4. When everything works the way you expect, uninstall Waypoint.
