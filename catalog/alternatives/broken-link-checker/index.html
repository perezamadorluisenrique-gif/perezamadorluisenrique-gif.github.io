Linkvane vs Broken Link Checker: which to pick

Both find broken links in your content. Broken Link Checker is far more widely used and has email alerts and an optional cloud engine; Linkvane is new and runs entirely on your own server. Here are the public facts and the differences.

Which one to pick

  • Pick Broken Link Checker if you want email alerts or a scanner hosted off your server, or if you prefer a long-established plugin with a very large user base.
  • Pick Linkvane if you want no accounts or third-party services, if you care that a link is only flagged after repeated failures, or if you also want to review your site’s internal links.

Linkvane is a young plugin and has no ratings yet. Read the reviews of both before deciding.

How to try Linkvane without removing Broken Link Checker

  1. Install Linkvane from wordpress.org and open it under Tools, Link Health.
  2. Click “Run Scan Now”. Linkvane scans your content from scratch: it does not import Broken Link Checker’s results or ignore list.
  3. So two scanners are not asking for the same links at once, deactivate Broken Link Checker (do not delete it) while you compare.
  4. If you stay with Linkvane, uninstall Broken Link Checker; if not, reactivate it.
