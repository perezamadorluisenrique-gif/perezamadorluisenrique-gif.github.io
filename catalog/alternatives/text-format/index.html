What Text Case and Cleanup does

Change the case of the text you have selected, and clean up prose that came out of a PDF, a scan or a web page.

How to switch from Text Format to Text Case and Cleanup

  1. Install Text Case and Cleanup from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Text Format off without deleting it, so the two do not act on the same action at once.
  3. Open the Text Case and Cleanup settings and review them once: settings from Text Format are not copied over.
  4. When everything works the way you expect, uninstall Text Format.
