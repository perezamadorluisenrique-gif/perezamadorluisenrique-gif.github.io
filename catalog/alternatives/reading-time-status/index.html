What Note Reading Time does

See how long the note in front of you takes to read, in the status bar.

How to switch from Reading Time Status to Note Reading Time

  1. Install Note Reading Time from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Reading Time Status off without deleting it, so the two do not act on the same action at once.
  3. Open the Note Reading Time settings and review them once: settings from Reading Time Status are not copied over.
  4. When everything works the way you expect, uninstall Reading Time Status.
