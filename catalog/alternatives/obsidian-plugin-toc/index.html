What Inline TOC does

One table of contents that is live while you read, plain Markdown when you publish, and never goes stale.

How to switch from Table of Contents to Inline TOC

  1. Install Inline TOC from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Table of Contents off without deleting it, so the two do not act on the same action at once.
  3. Open the Inline TOC settings and review them once: settings from Table of Contents are not copied over.
  4. When everything works the way you expect, uninstall Table of Contents.
