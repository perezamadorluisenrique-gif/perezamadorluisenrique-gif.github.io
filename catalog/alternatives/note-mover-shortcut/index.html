What Note Mover Rules does

Move notes into folders by ordered rules on tags, properties, titles and paths, with a preview before any bulk move.

How to switch from Advanced Note Mover to Note Mover Rules

  1. Install Note Mover Rules from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Advanced Note Mover off without deleting it, so the two do not act on the same action at once.
  3. Open the Note Mover Rules settings and review them once: settings from Advanced Note Mover are not copied over.
  4. When everything works the way you expect, uninstall Advanced Note Mover.
