What Spreadsheet to Table does

Table tools for Markdown notes: paste spreadsheet cells as a table, edit rows and columns from commands (so it works in source mode and on a phone), sort, align, and copy a table out as rich text, CSV or spreadsheet cells.

How to switch from Excel to Markdown Table to Spreadsheet to Table

  1. Install Spreadsheet to Table from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Excel to Markdown Table off without deleting it, so the two do not act on the same action at once.
  3. Open the Spreadsheet to Table settings and review them once: settings from Excel to Markdown Table are not copied over.
  4. When everything works the way you expect, uninstall Excel to Markdown Table.
