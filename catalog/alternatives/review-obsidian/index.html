What Revisit Later does

Link the current note into a future daily note, with a date typed in plain English, so it comes back when you want to review it.

How to switch from Review to Revisit Later

  1. Install Revisit Later from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Review off without deleting it, so the two do not act on the same action at once.
  3. Open the Revisit Later settings and review them once: settings from Review are not copied over.
  4. When everything works the way you expect, uninstall Review.
