What Folder Counts does

See how many notes each folder holds, right in the file explorer.

How to switch from File Explorer Note Count to Folder Counts

  1. Install Folder Counts from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn File Explorer Note Count off without deleting it, so the two do not act on the same action at once.
  3. Open the Folder Counts settings and review them once: settings from File Explorer Note Count are not copied over.
  4. When everything works the way you expect, uninstall File Explorer Note Count.
