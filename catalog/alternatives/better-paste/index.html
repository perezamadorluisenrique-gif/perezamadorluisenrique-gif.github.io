What Link Title on Paste does

Paste a web address and get a Markdown link with the page's title, Page title, without leaving the keyboard.

How to switch from Better Paste to Link Title on Paste

  1. Install Link Title on Paste from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Better Paste off without deleting it, so the two do not act on the same action at once.
  3. Open the Link Title on Paste settings and review them once: settings from Better Paste are not copied over.
  4. When everything works the way you expect, uninstall Better Paste.
