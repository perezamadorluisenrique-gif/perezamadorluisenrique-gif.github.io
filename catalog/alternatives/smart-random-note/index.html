What Random Note Filters does

Open or link a random note from a folder, tag, property or the current search results.

How to switch from Smart Random Note to Random Note Filters

  1. Install Random Note Filters from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Smart Random Note off without deleting it, so the two do not act on the same action at once.
  3. Open the Random Note Filters settings and review them once: settings from Smart Random Note are not copied over.
  4. When everything works the way you expect, uninstall Smart Random Note.
