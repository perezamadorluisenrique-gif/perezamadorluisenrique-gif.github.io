What URL Cards does

Turn a web address into a card with the page's title, description, image and site icon, in Reading view and Live Preview.

How to switch from Link Embed to URL Cards

  1. Install URL Cards from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Link Embed off without deleting it, so the two do not act on the same action at once.
  3. Open the URL Cards settings and review them once: settings from Link Embed are not copied over.
  4. When everything works the way you expect, uninstall Link Embed.
