What Update Radar does

Checks your installed community plugins and themes for updates in the background, shows what changed, and tells you which plugins look abandoned. A successor to Plugin Update Tracker, which has not had a release in over a year.

How to switch from Plugin Update Tracker to Update Radar

  1. Install Update Radar from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Plugin Update Tracker off without deleting it, so the two do not act on the same action at once.
  3. Open the Update Radar settings and review them once: settings from Plugin Update Tracker are not copied over.
  4. When everything works the way you expect, uninstall Plugin Update Tracker.
