What Emoji Search does

Insert emojis from a searchable picker or by typing a :shortcode.

How to switch from Emoji Toolbar to Emoji Search

  1. Install Emoji Search from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Emoji Toolbar off without deleting it, so the two do not act on the same action at once.
  3. Open the Emoji Search settings and review them once: settings from Emoji Toolbar are not copied over.
  4. When everything works the way you expect, uninstall Emoji Toolbar.
