How to switch from List Callouts to List Item Callouts

  1. Install List Item Callouts from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn List Callouts off without deleting it, so the two do not act on the same action at once.
  3. Open the List Item Callouts settings and review them once: settings from List Callouts are not copied over.
  4. When everything works the way you expect, uninstall List Callouts.
