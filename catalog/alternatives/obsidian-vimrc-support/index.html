What Vim Config does

Loads a vimrc-style file from your vault so your key mappings and editor commands are ready when vim mode starts.

How to switch from Vimrc Support to Vim Config

  1. Install Vim Config from Install from the Obsidian directory.
  2. In Settings, Community plugins, turn Vimrc Support off without deleting it, so the two do not act on the same action at once.
  3. Open the Vim Config settings and review them once: settings from Vimrc Support are not copied over.
  4. When everything works the way you expect, uninstall Vimrc Support.
