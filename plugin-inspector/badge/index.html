What the badge says

It is refreshed once a day from the manifest.json on your default branch, with the same manifest checks as the Inspector. The rules that only apply to new submissions (no "obsidian" or "plugin" in the name) are left out for plugins that are already listed.

  • healthy: no issues or notes.
  • N notes: advice only, such as a description without a final period.
  • N issues: something the directory expects is missing or wrong.
  • unknown: the manifest could not be read. This is never shown as healthy.

The release, versions.json and README checks are on the full Inspector page for your plugin, which the badge links to. Only plugins in the Obsidian directory have a badge. Unofficial; not affiliated with Obsidian. Shields.io draws the image when your README is viewed; nothing is sent to us.
